Parallelism: Amdahl ‘speed up’ graph plotter.

Observe that even if most of the code is parallelisable the speed-up can be quite limited. For example if 90% of the code can be parallelised the maximum possible speed-up is 10x. If half the code is parallelised the best (with an infinite number of processors) is a doubling. all this assumes there is no overhead in organising the parallel processing.
Try plotting at 100% parallel to see the limit.
